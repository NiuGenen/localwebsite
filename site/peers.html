                防火墙说明（重要）
                

                    
多数 Linux 发行版默认开启防火墙（firewalld / ufw），且只放行少数端口（如 ssh），其它端口一律拦截。若运行后门户显示「在线」但无法浏览/下载，通常是本机防火墙未放行 peer 端口。

                    
    
                        
  • 用 root 运行 sudo python3 peer.py：脚本会自动放行所选端口（关闭时自动移除规则），无需手动操作。
    • 
                        
  • 用普通用户运行：脚本会打印放行命令提示，手动执行一次即可；命令格式（以端口 9000 为例）：
                            
    # firewalld（CentOS/Rocky/Fedora 等）
sudo firewall-cmd --permanent --add-port=9000/tcp
sudo firewall-cmd --reload

# ufw（Ubuntu/Debian 等）
sudo ufw allow 9000/tcp
    
                        
    • 
                    

                    
若自定义了 --port，请把命令中的 9000 换成实际端口；修改端口后需重新放行。

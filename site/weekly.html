每周周报

查看每周工作汇总，进入周报后可提交或修改自己的内容。

使用脚本获取周报内容

局域网机器只需安装 Python 3，无需其他依赖。运行以下命令可下载脚本并立即输出最新周报：

curl -O http://192.168.8.65:8080/weekly.py && python3 weekly.py export

查询周报

python3 weekly.py help
python3 weekly.py
python3 weekly.py list --limit 10
python3 weekly.py list --json
python3 weekly.py people <周报ID>
python3 weekly.py people <周报ID> --json

help 显示所有操作；直接运行默认列出最新 5 个周报；list 可调整数量或输出 JSON；people 查看某周报中已提交的人员。

导出 Markdown

python3 weekly.py export
python3 weekly.py export <周报ID>
python3 weekly.py export <周报ID> --view person
python3 weekly.py export <周报ID> --person 张三
python3 weekly.py export --month 202608
python3 weekly.py export --year 2026 --person 张三
python3 weekly.py export --start-time 20260101 --end-time 20261231
python3 weekly.py export --year 2026 -o 2026年周报.md

省略周报 ID 时默认导出最新周报。可按项目或人员排列、筛选指定人员，也可按日期区间、月份或年份合并导出；只要周报与时间段部分重叠就会纳入，并按时间从早到晚排列。

脚本默认连接 http://192.168.8.65:8080。如需连接其他服务器，可在子命令前使用 --server http://服务器地址:端口，或设置 WEEKLY_SERVER 环境变量。
